# Decisions

Every product, design and technical call made while building, newest first. "Owner" means the owner decided;
"Claude" means Claude took its own recommendation under the standing permission of 23 Nov 2026 (reversible
calls only). Anything about money, legal, launch dates or customers goes to the owner.

| Date | Decision | Why | By | Undo by |
| --- | --- | --- | --- | --- |
| 23 Nov 2026 | At a shop's request an operator exports or deletes all of its data through `/v1/admin/pilot/export` and `/v1/admin/pilot/deletions`, which reuse the tested tenant export and deletion. Deleting needs the shop's exact name with its id; the owner does not confirm it through a link | Pilot owners have no sessions, so the existing session routes cannot serve them. A typed name stops an id pasted for the wrong shop from wiping it. Deletion carries out the shop's own request under the admin gate, like the retention prune; it is not an action Manut AI takes for the shop | Claude | Remove the two entries from `ADMIN_METHODS` in `apps/api/src/index.ts`, or add an owner link before the deletion runs |
| 23 Nov 2026 | `apps/api`'s Worker serves `apps/web` from the API's own origin: `/v1/*` and `/relay/*` always reach the Worker, even when opened in a browser; every other path is a web app file or its one page; `wrangler dev` and `wrangler deploy` build the web app first | The console needs no CORS, one Cloudflare Access application covers the console and the operator routes, and a deploy can never ship a missing or stale web app | Claude | Remove `build` and `assets` from `apps/api/wrangler.jsonc` and host `apps/web` elsewhere with `VITE_API_ORIGIN` set to the API |
| 23 Nov 2026 | The web app's pages refuse framing (`X-Frame-Options: DENY`, `frame-ancestors 'none'`) and send `no-referrer`, `nosniff` and `noindex`; approval pages are never stored; no full Content-Security-Policy yet | No other site can frame the Approve button and trick an owner into pressing it. A strict policy that is wrong would break the owner's page, so it waits for the real-phone pass | Claude | Edit `apps/web/public/_headers` |
| 23 Nov 2026 | The admin Access contract and the one-origin contract run inside `apps/api`'s `pnpm test`; the Access contract loads Miniflare through Wrangler | The Access contract had stopped running under pnpm's strict layout without anyone noticing; routing lives in config that only a real asset router can check | Claude | Take them out of the `test` script in `apps/api/package.json` |
| 23 Nov 2026 | Agent events travel as one flat JSON object (`type` plus GoSpark's field names); an unrecognised kind or value is kept as `unknown` instead of dropped; the timeline reducer is pure (the caller supplies the time and fresh ids) and always folds sub-agents into the lead's state | GoSpark never encodes its event enum, so a wire shape had to be chosen; keeping unknowns means an older app never loses rows from a newer agent | Claude | `packages/agent-events/src/events.ts` and `reducer.ts`; the helper's full list of interpretations is in the commit message |
| 23 Nov 2026 | The GitHub user `kunanon-ui` has write access to this repository as an outside collaborator, and the Claude GitHub app covers every repository in the organisation | The owner's Claude account is linked to GitHub as `kunanon-ui`, which is not an organisation member, so cloud routines could not see the repository; reconnecting Claude as KunanonJ would have cut cloud sessions off from the owner's other repositories | Owner asked, Claude chose the method | Remove `kunanon-ui` under the repository's Collaborators settings; set the Claude app back to selected repositories |
| 23 Nov 2026 | A cloud routine works on the repository at night (22:00 to 06:00 Bangkok, every 2 hours, Sonnet 5.5): one queued task per run, on a `cloud/<task>` branch with a draft pull request into the active `pilot/*` branch | Progress while the owner's Mac is closed; the schedule and model are the owner's choice | Owner | Pause or delete it at claude.ai/code/routines |
| 23 Nov 2026 | The GitHub Actions test workflow is manual only; tests run on the developer Mac before every commit | GitHub refused to start jobs for the organisation: a payment failed or the spending limit needs raising. Billing is the owner's call | Claude | Restore the `pull_request` trigger in `.github/workflows/test.yml` once billing is sorted |
| 23 Nov 2026 | `.claude/settings.json` denies pushing to main, force pushes, merging pull requests and staging or production deploys | The owner's limits hold in every permission mode, not only by habit | Claude | Edit the deny list |
| 23 Nov 2026 | A decision on an older revision is refused even when it is a decline; a helper can neither approve nor decline owner-only kinds | The person must act on the exact request they saw; stricter than GoSpark, which let a decline through | Claude | `evaluateDecision` in `packages/approval-core` |
| 23 Nov 2026 | PromptPay QR refuses any id that is not a 10-digit mobile number, a 13-digit national or tax id, or a 15-digit e-wallet id, and any all-zero id | A guessed id sends a customer's money to someone else | Claude | Loosen `targetOf` in `packages/promptpay` |
| 23 Nov 2026 | Pilot web pages use the design canvas's own CSS (`@manut/ui-kit`), not shadcn/ui; English first with every string in one table | Fastest route to pages that match the canvas; shadcn arrives with the desktop app in P3; Thai is parked | Claude | Swap the components when P3 starts |
| 23 Nov 2026 | Owners have no accounts in week 1: each reply is approved through a signed, single-use link that expires in 24 hours, with consent asked once on that page | The pilot runs over LINE; a login would slow every approval | Claude | Add LINE Login and keep the link as a fallback |
| 23 Nov 2026 | Operator routes stay behind the lifted backend's admin gate (Cloudflare Access plus the operator key) | Keeps the backend's security model unchanged | Claude | None needed |
| 23 Nov 2026 | Worker names `manut-api-*` and rate-limit namespaces of their own | A deploy from this repository can never replace or share counters with GoSpark's services | Claude | Rename in `apps/api/wrangler.jsonc` |
| 23 Nov 2026 | pnpm workspace; only esbuild and workerd may run install scripts | The Notion plan chose pnpm; every other install script stays blocked | Claude | `pnpm-workspace.yaml` |
| 23 Nov 2026 | The desktop app will be a fork of Oh My Hermes, with the Hermes bridge removed | Tauri 2 + React 19, tested, released on three systems; Monocode could not be checked | Claude | Decide before week 2's fork |
| 23 Nov 2026 | The backend is GoSpark's cloud code (Cloudflare Workers), lifted whole, instead of a new Node + Postgres server | Tenants, members, approvals, schedules, a vault and retention already exist with 449 tests | Owner | Port to Postgres if a real limit appears |
