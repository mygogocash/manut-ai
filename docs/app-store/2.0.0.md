## App Review notes

Paste into App Review Information › Notes. Keep the existing contact fields.

```
Manut AI replaces GoSpark in this record. No account is needed to review it: Practice mode runs a demo team inside the
app and never uses real shop data.

To review:
1. Open Manut AI and press "Continue on this computer", then "Skip for now".
2. Home opens in Practice mode (bottom left). Open Team in the side menu and choose Nam: a demo chat with its history.
   Type a message and press Send; the demo team answers inside the app.
3. Open Needs you to see what waits for approval. Nothing is sent, posted or paid until it is approved.
4. Open Settings (the "You" row at the bottom left). General › System says that this edition is updated by the
   Mac App Store; it has no updater of its own.
5. Settings › Under the hood › Providers lists the coding agents found on the Mac. Manut AI does not install any
   program: for one that is missing it says so and asks the person to install it themselves.

Coding agents and the temporary exceptions
Manut AI can work with command-line coding agents the person installed and signed in to themselves (for example in a
developer's home folder: ~/.claude, ~/.codex). Those programs keep their sign-in and settings in their own folders in
the user's home, and live in install folders such as ~/.local/bin or /opt/homebrew. A program Manut AI starts runs
inside Manut AI's sandbox, so the app asks for these temporary exceptions, each naming one folder:
- home-relative-path.read-write: ~/.manut (Manut AI's own data) and each agent's own folder, so a signed-in agent can
  read and save its sign-in, settings and sessions.
- home-relative-path.read-only: the folders the agents' programs are installed in, ~/.gitconfig, ~/.config/git and
  ~/.ssh (so git can commit and reach the person's own remotes), gh's settings, and the shell's startup files.
- absolute-path.read-only: /opt/homebrew and /usr/local, where Homebrew installs git, Node and the agents.
Nothing outside these folders is read unless the person picks a folder in the open panel. The app never listens for
connections. Without these exceptions the rest of the app still works, but no coding agent can run.

In this sandboxed edition a terminal cannot start (the sandbox does not allow a controlling terminal) and computer use
is off; the app says so where those features are.

The app uses encryption only through the system: HTTPS/TLS, and WebKit's WebCrypto for the end-to-end channel to the
person's own paired phone and for a local cache.
```

The owner should know, before submitting, that App Review refused GoSpark these same exception kinds
(`docs/app-store.md`, "The entitlements, and why each"). If a reviewer asks to see a coding agent run, they would need one
installed and signed in on the review Mac; no credentials are supplied.
