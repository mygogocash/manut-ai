Recent chats and the other held frames raced the app's wall-clock timer, which removes `mo-rise` 800 ms after an arrival whatever the animation clock says, so a slow runner reached `hold` with nothing left to hold. Every arrival in the app is a keyframe animation, so the transition filter checks the same thing | Claude | Drop `freezeClock` and the `instanceof CSSAnimation` test from `arrivals` |
