| 27 Nov 2026 | The nightly runs on a schedule from `.github/workflows/nightly-desktop.yml`, builds all four platforms (Apple silicon, Intel, Linux, Windows) one after another, and publishes `nightly.json` only when all four built. A night that built nothing new (the branch did not move) stops after one cheap job | A half-built night must never reach people who follow Nightly, and macOS minutes cost ten times a Linux one, so an unchanged branch builds nothing. Cost: four builds a changed night | Claude | Drop a matrix row in the workflow and `REQUIRED_PLATFORMS` in `.github/scripts/nightly.mjs` |
| 27 Nov 2026 | The nightly's version is the next patch number as a prerelease (`0.1.2-nightly.20261127` after stable 0.1.1), set with `--config` for that build only | The updater installs only a newer version and `0.1.1-nightly.x` is older than `0.1.1`, so the plain form would never be offered to a stable Mac. This form is newer than the stable it follows and older than the next stable. Cost: after a stable release bumps the version, nightlies of the same base are older than it until the base is bumped again | Claude | `nightlyVersion` in `.github/scripts/nightly.mjs` |
| 27 Nov 2026 | Nightly's feed is `https://github.com/mygogocash/manut-ai/releases/download/nightly/nightly.json`, a fixed prerelease tagged `nightly` that holds only that file and the commit the last good nightly was built from; each night's files are in `nightly-<date>` | GitHub has no "latest prerelease" address, and `releases/latest` skips prereleases, which also keeps nightlies from ever becoming stable's `latest.json`.
