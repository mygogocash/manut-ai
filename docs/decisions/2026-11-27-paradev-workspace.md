# Paradev workspace setup: how a new worktree gets ready

| Date | Decision | Why | By | Undo by |
| --- | --- | --- | --- | --- |
| 27 Nov 2026 | Paradev's workspace config is `.paradev/config.toml`, not the `.paradev/config.json` the setup request named | Paradev's own setup skill (CLI 2.0.12) calls `config.json` the old format and reads `config.toml` first. TOML holds one named terminal per dev server (desktop, tauri, web, api), where JSON holds a single run command | Owner | Replace `.paradev/config.toml` with a `config.json` of `setup`, `teardown` and `run` |
| 27 Nov 2026 | The api terminal keeps Wrangler's 8787 in the shared config. A Mac where another program holds 8787 sets that terminal's run, with `--port`, in its own `.paradev/config.local.toml`, which git now ignores | The README, `docs/runtime-adapter.md` and the desktop's Connected setting all use 8787. Wrangler stops with "Address already in use" rather than move to a free port, and the owner's Mac has another program on 8787, so that Mac uses 8791 | Owner | `[terminals.api]` in `.paradev/config.toml`; the ignore line in `.gitignore` |
| 27 Nov 2026 | Dependencies go in with `pnpm install --frozen-lockfile --prefer-offline`, in `[install]` | The command `.claude/skills/lead-merge/scripts/start-item.sh` already uses. It took 4 s with every package from the shared store, and a branch whose lockfile is out of step fails when its workspace is made instead of having its lockfile rewritten | Claude | `[install]` in `.paradev/config.toml` |
| 27 Nov 2026 | Setup copies the main checkout's ignored env files (`.env`, `.env.*`, `.dev.vars`, `.dev.vars.*`, down to an app's or a package's own folder) and never overwrites one the worktree has | A new worktree has none of them, and `wrangler dev` reads its local secrets from `apps/api/.dev.vars`. Never overwriting keeps a change made in the worktree when setup runs again. Only names are printed, since the setup terminal is on screen | Claude | `.paradev/setup.sh` and its tests in `.paradev/setup.test.mjs` |
| 27 Nov 2026 | The Run button starts the desktop front end in a browser (Practice, port 5207); tauri, web and api are terminals started when wanted. There is no `[archive]` (teardown) step | Practice needs no backend and no Rust, so it is the quickest look at the app. Setup starts nothing outside the worktree, and Paradev stops the terminals and deletes the worktree itself | Claude | `[terminals.*]` in `.paradev/config.toml`; an `[archive]` table for anything setup starts later |
