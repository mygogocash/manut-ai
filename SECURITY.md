# Security policy

Manut AI handles shop owners' messages, payments and account credentials, so we want to hear about a weakness
before anyone else does.

## Reporting a vulnerability

Please report it privately. Do not open a public issue, pull request or discussion about it.

Use GitHub's private vulnerability reporting: open
[Report a vulnerability](https://github.com/mygogocash/manut-ai/security/advisories/new), which is also under
this repository's **Security** tab. Only you and the maintainers can read the report, and we reply in it.

A useful report says what is affected, how to reproduce it, and what an attacker could do with it. Please test
against your own local copy (see `README.md`), never against a deployed service or a real shop's account.

## Supported versions

Manut AI is in its pilot and has no releases yet. Reports against the latest code on `main` are what we can act
on.
